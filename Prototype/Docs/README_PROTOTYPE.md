# BeatTapper — Prototype Overview

## Elevator Pitch (<= 100 words)
BeatTapper is a rhythm game where your inputs become the music. Tap, hold, and swipe to cues that match the track’s beat. On-time hits build combo and flow; misses briefly distort the mix and visuals, pushing you to recover. The appeal is performance: you are not only reacting to notes—you are performing the song.

## Project Synopsis
Lane-based rhythm prototype with splash screen, guide, play scene, and results.

## Objective
Clear songs with the highest accuracy and longest combo.

## Core Mechanics
- Inputs: D F J K for four lanes.
- Judgement: Perfect/Great/Good/Miss with combo multiplier.
- Feedback: on-beat hits brighten visuals; misses dim or distort.
- Flow aids: slightly relaxed windows after multiple misses.

- One playable track (Resources/BeatMaps/night_drive.json)
- Scenes: Splash, Guide, Play, Results
