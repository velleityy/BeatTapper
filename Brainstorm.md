# Brainstorm — **Beat Tapper** (working title)

**Core idea:** A minimal rhythm game where notes fall down the screen in sync with a song, and the player presses the matching keys when the notes reach the hit zone. The focus is tight timing and satisfying feedback, not complex visuals.

**Moment-to-moment gameplay:**
- Arrows (up, down, left, right) scroll toward the bottom.  
- Player presses the matching arrow key in time with the beat.  
- Scoring feedback: “Perfect / Good / Miss” flashes based on accuracy.  
- Combo counter and streak bonus encourage consistent play.  

**Stretch goals:** Multiple songs, difficulty levels (faster scroll speed, denser charts), leaderboard, and simple backgrounds that pulse to the beat.

**Tech plan:** Use Godot or Unity. Start with one track and hardcode beat timings. Later, add a simple level editor or JSON file for mapping notes. Prioritize accuracy in timing sync and clean UI feedback.

**Success criteria:** Player feels immediate connection between pressing keys and music, gets satisfying visual/audio feedback, and can finish one full track with clear results.
