# Inspiration

I’m inspired by my favorite arcade machine Andamiro's *Pump It Up* which is very similar to *Dance Dance Revolution*, but with 5 panels instead of 4. These games show how a very user-intuitive design can be fun and addictive if the timing feels responsive and the audio is engaging. I also enjoy how they can be scaled up or down—one song and a few beats already feels like a game, but adding more content can keep players hooked. This inspires me to focus on the core timing mechanic first, without worrying about large amounts of content or visuals.
